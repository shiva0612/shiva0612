## Key Highlights 

### Real-Time Market Data Platform

* Built and launched a **real-time market data platform from 0→1 in Golang**, processing live market ticks from **NSE, BSE, and MCX**.
* Designed the system from the ground up using **Redis** for scrip-level data storage, real-time **Option Greeks** calculation, and low-latency **LTP APIs** for the Order Management System (OMS).
* Built the complete **tick-to-candle pipeline**, generating 1-minute OHLC candles and serving them to downstream UI consumers through Redis.
* Developed technical-analysis capabilities from scratch, including **Three White Soldiers, Inverted Hammer**, and other candlestick patterns, with APIs to retrieve the latest patterns for requested scrips.

### Event-Driven Communication

* Designed an **event-driven Communication Manager** for **SMS, Email, and Push notifications**, supporting events such as order placement and fund addition.

### Performance & Platform Engineering

* Optimized critical **Holdings & Positions APIs**, reducing latency from **~2s to ~10ms**.
* Implemented **OpenSearch-based fuzzy search** and integrated **Setu UPI bank verification**.
* Built a centralized **Market Status API** supporting pre-market, market, post-market, and special trading sessions such as **Muhurat Trading**.
